# P01 — Лаборатория и репозиторий сервиса

Неделя 1. 10–12 часов. До начала: Базовая работа с файлами на своем компьютере.

Ты принимаешь небольшой внутренний сервис каталога. Команде нужен Linux-стенд и репозиторий, по которому другой инженер сможет повторить установку.

## Что важно понять

Процесс выполняет программу от имени пользователя. Файлы с исходным кодом, конфигурация и изменяемые данные имеют разный жизненный цикл. Git сохраняет выбранные изменения: рабочая директория, индекс и коммит — разные состояния.

## Задание

1. Подними отдельную Linux VM с systemd. Рекомендуемый стенд: поддерживаемая Ubuntu LTS, 2 vCPU, 4 ГБ RAM, 20 ГБ диска. На ARM используй ARM-образ. Запиши версии ОС и архитектуру.
2. Создай личного пользователя с sudo и подключись к VM по SSH-ключу. Закрытый ключ остается на твоем компьютере. Сохрани исходный снимок VM.
3. Распакуй starter-kit, создай свой Git-репозиторий, добавь remote на выбранном Git-хостинге и первый коммит. Проверь, что локальные данные и .env исключены из Git.
4. Разбери навигацию, относительные пути, поиск, конвейеры и перенаправления на файлах проекта. В docs/commands.md запиши 10 команд с объяснением результата.
5. Запусти приложение вручную по README стартового набора. Запроси /healthz, /version и /items. Запиши адрес, PID и порт процесса.
6. Опиши установку в docs/setup.md и внеси изменение текста README через ветку и pull request. Дай ментору ссылку на PR.

## Приемка

- После нового клонирования исходники и тесты доступны, временных файлов и секретов в истории нет.
- Ментор по инструкции подключается к учебному стенду и получает HTTP 200 от /healthz.
- Менти показывает разницу git diff и git diff --staged и объясняет один свой коммит.
- В setup.md есть версии, ресурсы VM, команда запуска и способ остановки процесса.

## Git

- Ветка p01/lab, PR с инструкцией и результатами запросов; не загружать приватные ключи. После приемки тег p01-done.

## Учебная неисправность

- Запусти команду из неверной директории и получи ошибку отсутствия app.py. Найди причину по pwd, ls и абсолютному пути, затем исправь инструкцию.

## Сдать

- README.md, docs/setup.md, docs/commands.md, ссылка на PR, текст запросов без секретов.
